\subsection{Little's Law check}
With the queue kept full, the number of outstanding I/Os $L$ should equal iodepth $\times$ numjobs, so
IOPS $\lambda$ and mean latency $W$ should satisfy $L = \lambda W$ \cite{little1961proof}.

\begin{table}[tbp]
  \centering\small
  \caption{Little's Law: measured $\lambda W$ against the configured queue depth.}\label{tab:littles-law}

    \pgfplotstabletypeset[
      col sep=comma,
      columns={iodepth,iops_median,lat_mean_us_median,lambdaW},
      create on use/lambdaW/.style={create col/expr={\thisrow{iops_median}*\thisrow{lat_mean_us_median}/1e6}},
      columns/iodepth/.style={column name=iodepth},
      columns/iops_median/.style={column name={$\lambda$ (IOPS)}, fixed, precision=0},
      columns/lat_mean_us_median/.style={column name={$W$ (\si{\micro\second})}, fixed, precision=1},
      columns/lambdaW/.style={column name={$L=\lambda W$}, fixed, precision=2},
