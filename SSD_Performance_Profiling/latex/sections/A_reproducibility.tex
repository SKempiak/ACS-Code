\section{Reproducibility}\label{app:repro}

Code and data live in this project's \code{code/} directory, the report in \code{latex/} (shared files in \code{common/}), at commit \code{65219fa68aef}.

\begin{lstlisting}[language=bash]
gh repo clone SKempiak/ACS-Code ACS && cd ACS
git checkout 65219fa68aef
make tools                                    # common/code/build/tools/summarize
make -C SSD_Performance_Profiling/code        # build/blkbench (O_DIRECT, libaio)
make -C SSD_Performance_Profiling/code test   # safety + sanity checks (~70 MiB written, deleted)
common/code/scripts/collect_env.sh --tex > common/latex/system_info.tex
export ACS_SCRATCH="$HOME/acs_ssd_scratch"    # a directory on the SSD under test
SSD_Performance_Profiling/code/scripts/run.sh dryrun   # device, link, space; writes nothing
SSD_Performance_Profiling/code/scripts/run.sh pitfall  # ran 2026-10-21 in run.sh all
SSD_Performance_Profiling/code/scripts/run.sh layout   # ditto
sudo fstrim -v /                              # 42.8 GiB at ~01:41; idle >= 30 min
SSD_Performance_Profiling/code/scripts/rerun_clean.sh  # run 20261022-021116
common/code/scripts/sync_data.sh SSD_Performance_Profiling
make ssd
\end{lstlisting}
\code{rerun_clean.sh} (\cref{sec:method}) first checks free space, drive idleness and recent-TRIM
evidence, then runs the steps of \cref{tab:budget} with their idle periods. Its console output
is in \code{data/raw/rerun_clean_20261022-021116.log}, and the root SMART log (taken after the
2026-10-21 runs) under \code{data/raw/smart/}. The superseded runs (\code{20261021-103201},
\code{20261021-105439}, and the lean \code{20261021-220614} with its \code{_lean} directories and log)
remain under \code{data/raw/}. Without \code{ACS_SCRATCH}, the in-repo
\code{data/scratch/} (an HDD here) is profiled; the safety gate applies either way. Knobs (\code{REPS},
\code{RUNTIME}, \code{WRITE_CAP_MIB}, \code{SUSTAIN_GIB}, \code{ENGINE=fio}, \dots) are documented in
\code{run.sh}.
