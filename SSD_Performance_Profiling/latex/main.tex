\begin{abstract}
  We profile a Micron 2210 \qty{512}{\giga\byte} QLC NVMe SSD on a PCIe~3.0~$\times$4 link with
  \code{O_DIRECT} I/O against disposable files, using a \code{libaio} benchmark cross-checked against FIO,
  in one scripted run that starts on a trimmed, idle drive and idles it between experiments.
  At QD=1, \qty{4}{\kibi\byte} random reads take
  \csvq[1]{zero_queue}{mode=read,pattern=rand}{lat_mean_us_median}\,\si{\micro\second}
  (\csvq{zero_queue}{mode=read,pattern=rand}{iops_median} IOPS) and writes
  \csvq[1]{zero_queue}{mode=write,pattern=rand}{lat_mean_us_median}\,\si{\micro\second}, because the
  write buffer hides the flash program. With one request in flight, sequential reads reach only
  \csvq{block_size}{bs=1048576,pattern=seq,mode=read,qd=1}{mibps_median}\,MiB/s even at
  \qty{1}{\mebi\byte}; at QD=32 they peak at
  \csvq{block_size}{bs=16384,pattern=seq,mode=read,qd=32}{mibps_median}\,MiB/s, \qty{56}{\percent} of
  the \qty{3756}{\mebi\byte\per\second} link, so the NAND back end is the ceiling. Random-read IOPS
  saturate at QD~\csvq{queue_depth_knee}{mode=read}{knee_qd}, and Little's Law confirms that the harness
  keeps the queue full. The SLC cache absorbed
  \csvval[1]{sustained_summary}{cliff_gib}\,GiB at \csvval{sustained_summary}{burst_mibps}\,MiB/s before
  sequential writes fell to \csvval{sustained_summary}{steady_mibps}\,MiB/s, but its size depends on
  drive state (\qty{3.8}{} and \qty{3.1}{\gibi\byte} in two earlier runs), and after a full fill it did not
  recover within a minute. Read p99.9 reaches \ssdtailratio{128}{p999}$\times$ the median at QD=128, and
  randomly written data reads 6--9$\times$ slower sequentially. Dropping \code{O_DIRECT} over-reports
  throughput
  \csvget\ssdBuf{pitfall}{mode=read-buffered}{iops_median}\csvget\ssdDir{pitfall}{mode=read}{iops_median}%
  \ssdratio[0]{\ssdBuf}{\ssdDir}$\times$ because it measures the page cache.
\end{abstract}
