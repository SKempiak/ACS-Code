\section{Reproducibility}\label{app:repro}

Code, scripts and raw data: \coderepo, on the \code{class-wide-project} submission branch (the exact
commit is recorded in \code{git log}).

\begin{lstlisting}[language=bash]
git clone https://github.com/SKempiak/ACS-Code.git && cd ACS-Code
git checkout <commit>
make tools                                    # tools/summarize
make -C SSD_Performance_Profiling             # build/blkbench (O_DIRECT, libaio)
make -C SSD_Performance_Profiling test        # safety + physical-ordering sanity checks
scripts/collect_env.sh --tex > ../ACS-Latex/common/system_info.tex
# Point the disposable-file scratch at the device you want to profile (here the NVMe SSD at /):
ACS_SCRATCH="$HOME/acs_ssd_scratch" SSD_Performance_Profiling/scripts/run.sh all
scripts/sync_data.sh SSD_Performance_Profiling
\end{lstlisting}

The \code{ACS_SCRATCH} override selects the device under test; the \code{safety.sh} gate is identical
wherever it points (a plain disposable file inside the scratch directory, never a device or mountpoint).
Omitting it profiles the in-repo \code{data/scratch/} filesystem instead.
