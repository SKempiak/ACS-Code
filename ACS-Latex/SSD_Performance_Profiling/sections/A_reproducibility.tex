\section{Reproducibility}\label{app:repro}

Code and data live in \code{ACS-Code/}, the reports in \code{ACS-Latex/}, at commit \code{c4f53e5adfc1}.

\begin{lstlisting}[language=bash]
gh repo clone SKempiak/ACS-Code ACS && cd ACS
git checkout c4f53e5adfc1
cd ACS-Code
make tools                                    # build/tools/summarize
make -C SSD_Performance_Profiling             # build/blkbench (O_DIRECT, libaio)
make -C SSD_Performance_Profiling test        # safety + sanity checks (~70 MiB written, deleted)
scripts/collect_env.sh --tex > ../ACS-Latex/common/system_info.tex
export ACS_SCRATCH="$HOME/acs_ssd_scratch"    # a directory on the SSD under test
SSD_Performance_Profiling/scripts/run.sh dryrun        # device, link, temperature, space; writes nothing
SSD_Performance_Profiling/scripts/run.sh all           # 2 GiB-file sweeps + fio_check (~23 min measured)
SUSTAIN_GIB=60 SSD_Performance_Profiling/scripts/run.sh device_state  # sustained + working set (needs 70 GiB free)
scripts/sync_data.sh SSD_Performance_Profiling
sudo fstrim -v /                              # lean re-run: 21:34:54, then idle >= 30 min
SSD_Performance_Profiling/scripts/rerun_clean.sh lean    # 20261021-220614, 22:06-22:32 EDT
scripts/sync_data.sh SSD_Performance_Profiling
cd ../ACS-Latex && make ssd
\end{lstlisting}
\code{rerun_clean.sh} (\cref{sec:method,tab:lean}) first checks free space, drive idleness and recent-TRIM
evidence; its full, non-lean mode has not been run. The lean run's console output is in \code{data/raw/rerun_clean_20261021-220614.log}, and the later root SMART log in
\code{data/raw/smart/20261021-2335_post_smart_log.txt}. Without \code{ACS_SCRATCH}, the in-repo
\code{data/scratch/} (an HDD here) is profiled; the safety gate applies either way. Knobs (\code{REPS},
\code{RUNTIME}, \code{WRITE_CAP_MIB}, \code{SUSTAIN_GIB}, \code{ENGINE=fio}, \dots) are documented in
\code{run.sh}.
