\section{Cache-Miss Impact}\label{sec:cache-miss}

\begin{hypothesis}
  As the SAXPY footprint grows past each cache, time per element should rise. Sequential traversal should
  rise gently---the prefetcher turns misses into hits---while a random permutation should rise sharply
  once the set leaves cache, because every element is an exposed miss.
\end{hypothesis}

  Kernel      & $y_i = a\,x_i + y_i$ (float64) \\
  Varied      & $N = 2^{8} \ldots 2^{24}$ (footprint); traversal order (sequential, random permutation) \\
  Counters    & \code{perf} unavailable (\cref{sec:method}); runtime is the proxy for miss rate \\

\subsection{Analysis}
Sequential SAXPY rises only from \qty{0.08}{\nano\second} per element in L1 to
\qty{0.81}{\nano\second} in DRAM---a \num{10}$\times$ span---because the prefetcher converts the regular
stream into mostly-hit accesses. Random traversal rises from \qty{0.46}{\nano\second} to
\qty{21.7}{\nano\second}, a \num{47}$\times$ span, with the steep climb beginning exactly where the
footprint ($16N$ bytes) leaves the L3 near $N=2^{20}$. The gap between the two curves at large $N$
(\num{\sim}27$\times$) \emph{is} the cache-miss cost that the prefetcher hides for sequential code; it is
the same prefetcher effect measured directly in \cref{sec:pattern}.

\subsection{AMAT interpretation}
\begin{equation}
  \text{AMAT} = t_{L1} + m_{L1}\bigl(t_{L2} + m_{L2}\,(t_{L3} + m_{L3}\, t_{\text{DRAM}})\bigr)
\end{equation}
Using the zero-queue latencies from \cref{tab:zero-queue}
($t_{L1}=\qty{1.0}{\nano\second}$, $t_{L2}=\qty{4.3}{\nano\second}$, $t_{L3}=\qty{11}{\nano\second}$,
$t_{\text{DRAM}}=\qty{84}{\nano\second}$), the fully-missing random case ($m\to1$ at every level) predicts
an AMAT near the DRAM latency, and the \qty{21.7}{\nano\second} per element we measure is below that
because SAXPY touches one \qty{8}{\byte} element per iteration (eight per line) and keeps several
independent misses in flight---memory-level parallelism amortises the \qty{84}{\nano\second} latency over
multiple elements. Because \code{perf} is unavailable we cannot report the per-level miss ratios $m_{Li}$
that would make this quantitative, so the AMAT reading here is illustrative; the measured curve is the
primary evidence.
