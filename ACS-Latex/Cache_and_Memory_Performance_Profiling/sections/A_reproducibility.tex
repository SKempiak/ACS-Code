\section{Reproducibility}\label{app:repro}

Code, scripts and raw data: \coderepo, on the \code{class-wide-project} submission branch (the exact
commit is recorded in \code{git log}).

\begin{lstlisting}[language=bash]
git clone https://github.com/SKempiak/ACS-Code.git && cd ACS-Code
git checkout <commit>
make tools                                            # tools/summarize
make -C Cache_and_Memory_Performance_Profiling        # mem_latency / mem_bandwidth / kernel_miss
make -C Cache_and_Memory_Performance_Profiling test   # safety + physical-ordering sanity checks
scripts/collect_env.sh --tex > ../ACS-Latex/common/system_info.tex
CPU_PIN=2 Cache_and_Memory_Performance_Profiling/scripts/run.sh all
scripts/sync_data.sh Cache_and_Memory_Performance_Profiling
\end{lstlisting}
