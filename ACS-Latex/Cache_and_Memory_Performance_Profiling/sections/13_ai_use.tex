\section{AI-Use Note}\label{sec:ai-use}

Summarized from \code{AI_USE_LOG.md} in the code repository.

\begin{description}[style=nextline]
  \item[Tools used] Claude Code (Claude Opus~5) for coding, debugging and drafting this report;
        GCC~\sysGCC{} for the builds. The AI wrote code and prose. The timed experiments were also run by Claude Code, on the
        user's machine (\cref{tab:environment}) and with the user's approval, after the user had set the
        frequency governor, disabled turbo and taken the SMT siblings offline. Every number comes from
        those runs.
  \item[What they helped generate] The four microbenchmarks---\code{mem_latency} (Sattolo
        pointer-chase with access-size, page-size and counter options), \code{mem_bandwidth} (multi-thread
        streaming with read/write/copy/triad/rwmix and access-size modes), \code{mem_loaded} (loaded-latency
        probe with streaming, read/write and known-concurrency generators) and \code{kernel_miss}
        (footprint-varying SAXPY with counters)---the shared helpers, the \code{perf_event_open} counter
        code, the experiment driver (\code{run.sh}), \code{derive.py} and drafts of these sections.
  \item[What was independently modified, tested, or rejected] Eight concrete corrections.
        (1)~The first latency benchmark used a \emph{sequential} stride, which the prefetcher turned
        into a \ensuremath{\sim}\qty{5}{\nano\second} ``latency'' (really throughput); it was replaced with a random
        Sattolo cycle so exactly one request is outstanding---the sequential curve is now kept only as
        a deliberate contrast in \cref{fig:working-set}. (2)~The huge-page experiment initially
        \emph{assumed} THP backing because the governor was \code{always}; adding a runtime
        \code{/proc/self/smaps_rollup} check revealed \code{AnonHugePages: 0 kB}, turning a false
        ``huge pages don't help'' into an honest limitation (\cref{sec:tlb}). (3)~An AI-suggested
        bandwidth test defaulted to a small buffer and reported \qty{56}{\gibi\byte\per\second} as
        ``DRAM bandwidth''; this is the cache-reuse pitfall and is now documented as the required
        negative case (\cref{sec:pitfall}) rather than quoted as a result. A review of the first
        report against the rubric then found four more problems, all fixed and re-measured:
        (4)~the read/write-mix kernel mixed \qty{8}{\byte} elements, so every line moved in both
        directions (\cref{sec:rw-mix}); (5)~the throughput--latency knee was placed by eye and Little's
        Law used the zero-queue latency---replaced by a concurrent loaded-latency probe, an objective
        knee criterion and a known-concurrency check (\cref{sec:intensity}); (6)~the scalar unit-stride
        kernel had been quoted as the single-core peak although strided data contradicted it
        (\cref{sec:pattern}); (7)~a ``\qty{4}{\kibi\byte}'' buffer could silently receive huge pages
        under THP \code{always}, so the page policy is now set explicitly and verified
        (\cref{sec:tlb}). Table and prose numbers are now generated from the CSVs, after a hand-copied
        table was found to disagree with its data file.
        (8)~When the final data were analysed, the AI's first ``validation'' of Little's Law
        ($L/N\approx1$ in the known-concurrency sweep) turned out to be an accounting identity; it was
        replaced by $L_{\text{mem}}$ with the probe-measured memory latency (\cref{sec:intensity}). The
        knee rule was likewise changed to follow offered load rather than delivered bandwidth, which is
        noisy past saturation.
  \item[Validation] Sanity checks in \code{scripts/validate.sh} assert the physically necessary
        orderings (L1 $<$ L2 $<$ L3 $<$ DRAM latency; L1 bandwidth $>$ DRAM; multi-thread $>$
        single-thread; loaded $>$ unloaded latency); its output is saved with every experiment. Hardware counters (read directly through
        \code{perf_event_open}) confirm the miss level behind every latency step. Intel MLC was
        unavailable for an external cross-check; the substitutes and their limits are stated in
        \cref{sec:validation,sec:anomalies}. Every figure traces to a committed
        raw/processed file (\cref{app:repro}).
\end{description}
