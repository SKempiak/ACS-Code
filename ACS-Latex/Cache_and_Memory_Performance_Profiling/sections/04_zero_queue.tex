\section{Zero-Queue Baselines}\label{sec:zero-queue}
\rubric{Zero-queue baselines}{25}{Methodologically sound per-level latency measurements with clear units and caveats.}

\begin{hypothesis}
  With a single dependent access in flight, latency should rise in steps at the L1 (\qty{32}{\kibi\byte}),
  L2 (\qty{256}{\kibi\byte}) and L3 (\qty{20}{\mebi\byte}) capacities. We expect roughly 4--5 cycles for
  L1, \ensuremath{\sim}\num{12}~cycles for L2, a few tens of cycles for L3, and \ensuremath{\sim}\qty{80}{\nano\second}
  (hundreds of cycles) for DRAM, matching Skylake-family numbers.
\end{hypothesis}

\begin{knobs}
  Fixed       & one thread pinned to CPU~2; random (pointer-chase) reads; one node per \qty{64}{\byte} line \\
  Varied      & working-set size placed in L1, L2, LLC, DRAM \\
  Script      & \code{Cache_and_Memory_Performance_Profiling/scripts/run.sh latency} \\
\end{knobs}

The ring is a single random cycle (Sattolo) over one node per cache line, so each load depends on the
previous one and exactly one request is outstanding---zero-queue latency. Cycles use the in-process
effective frequency (\cref{sec:method}); the full size sweep and the sequential/random comparison are in
\cref{sec:pattern,sec:working-set}. Values are medians from \code{data/latency.csv}.

\subsection{Analysis}
The steps fall exactly where the cache capacities predict: latency is flat at \ensuremath{\sim}\num{4.9} cycles
while the set fits in L1, rises through the high teens at the \qty{256}{\kibi\byte} L2 edge, sits in the
tens of cycles across the \qty{20}{\mebi\byte} L3, and jumps to \ensuremath{\sim}\num{400} cycles once the set
no longer fits in LLC. The single sequential DRAM row (\qty{5.26}{\nano\second}) is a deliberate caveat:
it is \emph{not} a latency measurement but the prefetcher's throughput in disguise, which is why the
pointer chase is randomized. Residual caveats: the measured frequency floats with turbo, so the cycle
column carries a few-percent uncertainty; and the L3 figure is a single-core view of a shared cache, so
it reflects an otherwise-idle LLC. We could not cross-check against Intel MLC because it is not installed
(\cref{sec:method}); the hierarchy shape and the 4--5 cycle L1 anchor are our internal cross-checks.
