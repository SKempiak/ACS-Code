\section{Reproducibility}\label{app:repro}

\newcommand{\acscommit}{\detokenize{2721691f277e}}
Code, scripts, raw data and this report live in one repository: \code{ACS-Code/} holds the code and
data (this project in \code{ACS-Code/SIMD_Advantage_Profiling/}, shared helpers in
\code{ACS-Code/common/} and \code{ACS-Code/tools/}), \code{ACS-Latex/} the reports (this one in
\code{ACS-Latex/SIMD_Advantage_Profiling/}). Every result in this report was produced from commit
\texttt{\acscommit}. From the repository root:

\begin{lstlisting}[language=bash]
gh repo clone SKempiak/ACS-Code ACS && cd ACS
git checkout 2721691f277e
cd ACS-Code
make tools                                # tools/summarize
make -C SIMD_Advantage_Profiling          # scalar/autovec/native simd_bench + ceilings
make -C SIMD_Advantage_Profiling test     # 578 correctness cases
make -C SIMD_Advantage_Profiling report   # vectorization evidence
scripts/collect_env.sh --tex > ../ACS-Latex/common/system_info.tex
SIMD_Advantage_Profiling/scripts/run.sh all     # ceilings, baseline, locality, alignment,
                                                # stride, dtype, negative
scripts/sync_data.sh SIMD_Advantage_Profiling   # -> ACS-Latex/SIMD_Advantage_Profiling/data/
cd ../ACS-Latex && make simd                    # -> SIMD_Advantage_Profiling.pdf
\end{lstlisting}
Hardware counters need no root (user-space events, \code{perf_event_paranoid} $\le 2$); with
\code{COUNTERS=0}, or where they cannot be opened, \code{run.sh} skips the counter outputs.
\code{run.sh derive} recomputes the derived tables (roofline points and roofs, per-level bandwidth,
stride summary) from the processed CSVs without measuring.

Each raw directory holds \code{raw.csv} (one row per repetition, with full configuration metadata)
and \code{env.txt} (a snapshot of \code{collect_env.sh}); the processed CSVs plotted above are
produced from them by \code{tools/summarize} plus this project's post-processing scripts
(\code{speedup_iqr.awk}, \code{roofline.sh}, \code{tables.sh}) and copied into this report's
\code{data/} by \code{scripts/sync_data.sh}. Every number quoted in the report traces to one of these
files.
